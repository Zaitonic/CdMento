# Documentation

Start with the root [README](../README.md) to run CdMento locally.

- [Project structure](PROJECT_STRUCTURE.md) — where source, configuration, output, and data live.
- [AI setup](AI_SETUP.md) — your own provider keys, free-plan checks, automatic routing, and integration limits.
- `examples/` — sample study material; nothing is automatically imported into accounts.
- `plans/` — earlier design and research notes. These describe planning history, not necessarily the current implementation.
- `history/` — earlier implementation snapshots. Current behavior is documented in the README and AI setup guide.
- `licenses/` — third-party attribution notices.
